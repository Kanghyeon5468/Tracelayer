# One-Month Build Roadmap

## Week 1: Secure Core Runtime

- Finish Agent Gateway, policy engine, guardrails, memory bank, and audit ledger.
- Add realistic mock data for multiple fraud typologies.
- Create repeatable local demo scripts.

## Week 2: Google Cloud Integration

- Deploy API to Cloud Run.
- Create Pub/Sub topics and worker subscriptions.
- Move case memory to Firestore.
- Move related transaction search to BigQuery.
- Add Vertex AI Gemini calls behind guardrail hooks.

## Week 3: Investigation UX

- Add graph visualization for accounts, devices, IPs, and counterparties.
- Add approval workflow screens.
- Add report export flow.
- Add audit viewer for compliance reviewers.

## Week 4: Hardening and Submission

- Add load and failure-mode tests.
- Capture Cloud Console evidence for the demo video.
- Polish architecture diagram and demo script.
- Write final Devpost submission and record the four-minute demo.
